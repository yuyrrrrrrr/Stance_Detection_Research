# C-STANCE EDA 报告大纲（面向 DG + DA 的中文零样本立场检测）

> 配套代码：`analysis/eda_full.py`；图表：`analysis/output/figs/`；结果已用真实数据填充。

---

## 一、数据基本信息

1. **数据集来源与任务**：C-STANCE（ACL 2023），中文零样本立场检测，标签 = {支持, 反对, 中立}。
2. **规模**：
   - Subtask A（目标级零样本）：train 33,418 / val 7,284 / test 7,424。
   - Subtask B（领域级零样本，留一域）：7 个域 × (train/val/test)，测试为纯单域。
3. **字段结构**：`Text / Target 1 / Stance 1 / [Domain] / [In Use] / Type`（onecol：一目标一行，一个文本约挂 5 个目标）。
4. **标签编码**：`支持→0, 反对→1, 中立→2`（原始为中文，非数值）。
5. **目标类型**：`noun_phrases`（40%，短，平均 3~4 字）与 `clauses`（=论文 claim，60%，长，平均 25~26 字）。
6. **数据质量**：无缺失值、无重复行；文本已被清洗（无 @/URL/#话题#/emoji），**无需预处理清洗**。

## 二、关键发现

### 2.1 标签分布（整体均衡，跨域漂移）
- 整体三类 ≈ 1/3（支持 34.3% / 反对 33.2% / 中立 32.5%），train/val/test 高度一致 → **类别不平衡不是主要矛盾**。
- **跨域标签漂移明显**：中立占比 28.6%（权益）~ 40.6%（世界事件），差距 **12pp**；世界事件/体育偏中立，权益/新冠偏反对。

### 2.2 目标极端稀疏（零样本核心难点）
- 训练集 25,787 个目标中 **94.2% 只出现一次**（median=1，mean=1.30，max=189）。
- 高频目标 Top-20：男女平等(189)、世界杯(168)、居家办公(165)、垃圾分类(136)、疫情(133)、鸡娃(120)、素质教育(112)、女拳(112)、俄罗斯(110)…

### 2.3 领域差异（DG 动机）
- 测试样本量：娱乐和消费最多（10,163），环保最少（3,649）→ 领域不均衡。
- 跨域测试目标重叠极小（0.25%~2.29%）→ **目标词表是强领域信号**。
- 文本长度差异小（96~108 字），claim 占比各域稳定 ~60%。

### 2.4 零样本划分质量
- Subtask A：train∩test 有 **84 个重叠目标**（占 test 1.1%），**非严格零样本**；重叠项几乎全是**模板化/近重复的 claim**（如"打疫苗可以更好/更好地保护我们…"、"XX问题一直受到人们的关注"）。
- Subtask B：7 个留出域全部 **PASS**（测试域在训练中完全未出现；`In Use==0` 已按官方剔除，每划分剔除 2,162~6,176 条）。

## 三、对建模的启示

1. **损失函数**：整体类别均衡 → 无需 Focal Loss / 类别加权；重点应放在**目标级**与**领域级**的分布鲁棒（如 IRM、CORAL、DANN、Group-DRO）。
2. **数据增强策略（按收益排序）**：
   - ① 目标级增强（最高优先级）：目标同义改写、claim 模板扩写、目标替换挖掘——直击 94% 目标只出现一次的痛点。
   - ② 领域级增强：针对小域（环保）跨域迁移/回译，缓解领域样本与标签分布漂移。
   - ③ 隐式表达增强：粗筛 ~3.9% 文本含反讽/网络用语，可引入思维链（先显式化立场线索）增强鲁棒性。
3. **领域泛化重点**：利用"跨域目标几乎不重叠 + 中立占比 12pp 漂移"这一结构，评估模型在未见域的标签偏移与目标偏移下的表现。
4. **目标类型分治**：noun_phrases 与 claim 粒度差异大，建模/增强应分开设计（如不同的 target encoder 输入模板）。

## 四、潜在问题与风险

1. **数据泄露**：Subtask A 的 84 个模板化 claim 重叠（train∩test），建议复现时显式清洗或报告该影响。
2. **标签噪声**：隐式/反讽表达（~3.9%）易被误标，尤其"支持/反对"边界；模板化 claim 可能存在构造噪声。
3. **模板化 claim 双刃剑**：数据集含大量机器生成模板 claim，既是 DA 参照，也可能引入捷径特征（shortcut）——模型可能学到模板而非法立场推理。
4. **In Use==0 样本被丢弃**：每划分数千条 LexsimTopics 样本未用，可作半监督/难负样本资源，但也需防目标泄露。
5. **领域命名差异**：`Type` 列用 `clauses`（=论文 claim）；`环保` 文件夹名拼写为 `enviromental_protection`（官方拼写，注意路径匹配）。
